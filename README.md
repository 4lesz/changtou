# 畅投 · 投影仪 DLNA 投屏接收端

装在安卓投影仪、电视盒子、智能电视上的**免费**投屏接收端。平板、手机上的视频 App 点“投屏”，选中“畅投”就能在大屏上播放。

- 免费，没有广告，不用注册账号
- 不收集任何数据，不联网上报（见 [隐私说明](PRIVACY.md)）
- 遥控器就能操作完所有界面
- 开机自动运行，投影仪打开后直接投，不用先进 App

> **当前是预览版**：已在 Android TV 模拟器上测试通过，还在投影仪真机上验证中。遇到问题欢迎[反馈](../../issues/new/choose)。

## 下载

到 [Releases](../../releases) 页面下载最新版本，每个版本有两个安装包：

| 安装包 | 大小 | 适合谁 |
| --- | --- | --- |
| `changtou-<版本号>.apk`（普通版） | 约 1.3 MB | **先装这个**，绝大多数在线视频够用 |
| `changtou-<版本号>-enhanced.apk`（增强版） | 约 40 MB | 普通版提示“格式不支持”、视频没有声音（AC3/DTS 音轨）、要播 RMVB/WMV 时再装这个 |

两个版本可以直接互相覆盖安装，设置会保留。以后升级也是直接覆盖安装，不用先卸载。

系统要求：安卓 5.0 及以上，ARM 处理器（市面上的投影仪、电视盒子基本都是）。

## 安装

**用 U 盘**：把 APK 拷到 U 盘，插到投影仪上，用投影仪的“文件管理”打开安装。提示“禁止安装未知来源应用”时，按提示到系统设置里允许。

**用电脑（ADB）**：投影仪打开 ADB 调试后，在电脑上执行（IP 换成投影仪的地址）：

```
adb connect 192.168.1.100
adb install -r changtou-1.0.4-xx.apk
```

## 第一次使用

1. **装好后打开一次畅投**。安卓规定，从没打开过的应用收不到开机通知，打开一次以后开机就会自动运行。
2. **开启悬浮窗权限**（安卓 10 及以上）：首页底部出现黄色提醒时，按确认键去开启。开了以后，投影仪停在别的界面时收到投屏也能自动弹出画面。
3. 平板或手机连上**和投影仪同一个 Wi-Fi**，在视频 App 里点投屏图标，选择“畅投”开头的设备。

## 能做什么

| 功能 | 说明 |
| --- | --- |
| 视频投屏 | 支持 m3u8、MP4、FLV、TS、MKV、DASH 等常见格式；4K、HEVC 取决于投影仪芯片 |
| 音乐、图片投屏 | 音乐显示歌名和封面，图片全屏显示 |
| 平板控制 | 在平板上暂停、拖进度、调音量、换集，投影仪立即响应，进度条同步 |
| 遥控器控制 | 确认键暂停/继续，左右键快退/快进 10 秒（长按加速），音量键调音量，返回键退出；操作会同步回平板 |
| 播放菜单 | 播放时按下键或菜单键打开：倍速（0.75×–2×）、画面比例、音轨切换、滤镜 |
| 滤镜 | 明亮、鲜艳、暖色、电影、黑白，也可以自己调；还能用手机浏览器导入 .cube 调色预设 |
| 自动连播 | 发送端支持连播时，自动播放下一集 |
| 抢着投 | 家人用另一台设备投新视频，直接替换当前播放 |
| 网络自愈 | 换 Wi-Fi、断网恢复后自动重新上线，不用重启 |
| 出错提示 | 链接失效、格式不支持、网络超时时，屏幕上显示中文原因 |
| 设置 | 设备名称、开机自动运行、解码方式、画面比例、进度条显示时长 |

## 支持哪些 App

畅投使用公开的 DLNA 标准协议。凡是投屏列表里能显示“电视/DLNA 设备”的 App，一般都能投，例如 B站、BubbleUPnP、各家视频 App、网盘、浏览器，以及 Windows 的“播放到设备”。

各个 App 的实测结果会持续更新在这里。你试过某个 App 能投或不能投，欢迎用[兼容性反馈](../../issues/new?template=compat.yml)告诉我们。

**畅投做不到的事**：

- 不能绕过会员、版权加密（DRM）或 App 自己对投屏设备的限制。这类片源投不了属于正常情况，屏幕上会提示原因。
- 不支持乐播、奇异果等厂商私有投屏协议。如果某个 App 的投屏列表里只认这些协议，就搜不到畅投。
- 不能做屏幕镜像（把平板整个屏幕投过去）。

## 常见问题

**平板搜不到“畅投”？**

1. 确认平板和投影仪连的是同一个 Wi-Fi（2.4G 和 5G 是同一个路由器的通常也可以）。
2. 打开畅投首页，看右上角状态是不是“等待投屏”。
3. 有些路由器开了“AP 隔离”“访客网络”或屏蔽了组播，设备之间互相看不见，需要在路由器设置里关掉。
4. 投影仪自带投屏也可能占用同一个端口，首页会提示；设备名默认带“畅投”二字，方便和自带投屏区分。

**投影仪重启后搜不到？**

到设置里确认“开机自动运行”是开的。部分投影仪系统带“自启动管理”“后台管理”或清理功能，需要在系统的应用管理里允许畅投自启动、后台运行。设置页的“开机后搜不到？”里有说明。

**在别的界面投屏，画面不弹出来？**

需要悬浮窗权限。在设置里看“悬浮窗权限”是否已开启；系统里找不到开启入口时，可以用电脑执行：

```
adb shell appops set com.changtou.dmr SYSTEM_ALERT_WINDOW allow
```

**有画面没声音？**

多半是视频的音轨是 AC3 或 DTS，投影仪自己解不了。安装增强版即可。

**卡顿、花屏或黑屏？**

到设置里把“解码方式”换一种试试（下一个视频生效）；还不行就装增强版。
